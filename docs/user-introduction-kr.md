# TripWeave 사용자 소개

TripWeave는 여러 사람이 찍은 여행 사진을 모아 하나의 여행 이야기로 재구성해 주는 앱입니다.

여행이 끝난 뒤 각자의 휴대폰과 카메라에 흩어진 사진을 TripWeave에 올리면, 앱은 사진의 시간과 위치 정보를 바탕으로 여행을 날짜, 장소, 순간 단위로 정리합니다. 사용자는 잘못 추정된 부분만 검토하고 고친 뒤, 지도와 타임라인이 함께 있는 인터랙티브 여행 스토리로 공유할 수 있습니다.

## 누구를 위한 앱인가요?

TripWeave는 이런 상황에 잘 맞습니다.

- 가족, 친구, 동료와 함께 다녀온 여행 사진을 한곳에 모으고 싶을 때
- 여러 사람이 찍은 사진을 시간순으로 다시 정리하기 어려울 때
- 여행 동선을 지도 위에서 되짚어 보고 싶을 때
- 사진 앨범보다 더 살아 있는 여행 기록을 만들고 싶을 때
- 원본 사진과 민감한 위치 정보를 그대로 공개하지 않고 안전하게 공유하고 싶을 때

## TripWeave가 해주는 일

TripWeave의 핵심 역할은 흩어진 사진을 하나의 공동 여행 기록으로 엮는 것입니다.

1. 여행 만들기

   여행 소유자가 새 여행을 만들고 제목, 날짜, 시간대 같은 기본 정보를 설정합니다.

2. 참여자 초대하기

   함께 여행한 사람들을 초대해 각자의 사진을 올릴 수 있게 합니다. 참여자는 자신이 올린 미디어에 대한 소유권과 삭제 권한을 가집니다.

3. 사진 업로드하기

   참여자들이 JPEG 또는 HEIC 사진을 업로드합니다. 원본 파일은 공개용 콘텐츠가 아니라 처리를 위한 비공개 입력물로 다룹니다.

4. 자동 정리하기

   TripWeave는 사진에서 촬영 시각, 위치, 파일 정보 등을 추출하고, 이를 바탕으로 여행을 날짜, 이동 구간, 방문 장소, 작은 순간들로 묶습니다.

5. 예외만 검토하기

   사용자가 모든 사진을 일일이 확인할 필요는 없습니다. TripWeave는 시간이 없거나, 위치가 불확실하거나, 날짜가 어긋났을 가능성이 있는 항목처럼 사람의 판단이 필요한 부분을 우선 보여줍니다.

6. 수정하고 확정하기

   사용자는 잘못된 시간, 위치, 묶음, 공개 여부 등을 고칠 수 있습니다. 사용자가 직접 고친 값은 자동 추정보다 우선합니다.

7. 여행 스토리 공유하기

   정리된 여행은 지도와 타임라인이 결합된 스토리로 볼 수 있습니다. 공개용 스토리는 원본이 아니라 민감한 정보가 제거된 파생 이미지와 정리된 데이터만 사용합니다.

## 주요 기능

### 공동 사진 수집

여행마다 참여자를 초대하고, 여러 사람이 각자의 사진을 업로드할 수 있습니다. TripWeave는 누가 어떤 미디어를 올렸는지 기록하고, 참여자의 미디어 소유권을 존중합니다.

### 시간과 위치 기반 자동 정리

사진의 촬영 시간과 GPS 정보를 활용해 여행 흐름을 재구성합니다. 같은 날의 사진, 같은 장소에서 찍은 사진, 함께 이어지는 순간들을 묶어 여행의 구조를 만듭니다.

### 지도와 타임라인

TripWeave의 최종 경험은 단순한 사진 목록이 아닙니다. 사용자는 지도에서 이동 경로와 방문 지점을 보고, 타임라인에서 날짜와 순간의 순서를 따라가며 여행을 탐색할 수 있습니다.

### 검토가 필요한 항목만 강조

자동 정리가 항상 완벽할 수는 없습니다. TripWeave는 확신이 낮은 결과, 누락된 위치, 알 수 없는 시간, 잘못 묶였을 가능성이 있는 장소 등을 검토 항목으로 보여주어 사용자가 중요한 부분에만 집중할 수 있게 합니다.

### 사용자 수정 우선

사용자가 직접 수정한 시간, 위치, 그룹, 공개 설정은 자동 결과보다 우선합니다. 이후 다시 자동 정리를 실행하더라도 사람이 확정한 판단은 보존하는 방향으로 설계되어 있습니다.

### 안전한 공개 스토리

공개 스토리는 원본 사진을 그대로 노출하지 않습니다. 민감한 메타데이터를 제거한 파생 이미지와 공유에 적합한 지도 정보만 사용해, 여행을 보여주면서도 개인정보 노출 위험을 줄입니다.

### 로컬 우선 동작

TripWeave는 먼저 로컬에서 완전한 MVP를 검증하는 방향으로 만들어졌습니다. 기본 동작은 로컬 파일 저장소, 로컬 데이터베이스, 로컬 처리 작업을 중심으로 하며, 특정 클라우드 서비스에 종속되지 않도록 설계되어 있습니다.

## 사용자가 경험하는 기본 흐름

1. 계정을 만들고 로그인합니다.
2. 새 여행을 만듭니다.
3. 함께 여행한 사람을 초대합니다.
4. 각 참여자가 사진을 업로드합니다.
5. TripWeave가 사진을 처리하고 여행 구조를 만듭니다.
6. 소유자나 편집자가 검토 항목을 확인하고 필요한 부분을 수정합니다.
7. 정리된 여행을 지도와 타임라인으로 둘러봅니다.
8. 필요하면 공개용 스토리 스냅샷을 만들어 공유합니다.

## 개인정보와 소유권

TripWeave는 여행 사진, 촬영 위치, 시간, 참여자 정보가 민감한 개인 데이터라는 전제에서 출발합니다.

- 원본 파일은 공개 스토리에 사용하지 않습니다.
- 원본 메타데이터는 비공개 정보로 다룹니다.
- 참여자는 자신이 올린 미디어에 대한 소유권과 삭제 통제권을 가집니다.
- 공개 스토리에는 민감한 정보가 제거된 파생 이미지와 정리된 데이터만 포함됩니다.
- 공개 링크는 원본 저장 위치나 영구적인 저장소 URL을 노출하지 않습니다.

## TripWeave가 아닌 것

TripWeave는 단순한 사진 저장소나 클라우드 백업 서비스가 아닙니다. 모든 원본 사진을 영구 보관하는 것이 핵심 목표도 아닙니다.

TripWeave의 목적은 여러 사람의 사진을 모아 여행의 흐름을 이해하고, 검토하고, 공유 가능한 이야기로 만드는 것입니다. 원본 보관보다 여행의 구조, 공동 기억, 안전한 공유 경험에 초점을 둡니다.

## 한 문장으로 말하면

TripWeave는 여러 사람의 여행 사진을 날짜, 장소, 순간으로 엮어 지도와 타임라인이 있는 안전한 공동 여행 스토리로 만들어 주는 앱입니다.
